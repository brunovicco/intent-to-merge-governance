# Production limitations

Publication as research software is not production approval. The following are blocking for any production claim: independent administration of all control identities and signer; isolated hostile candidate execution and independently trustworthy observation; service authentication and key lifecycle; real independent human approval and revocation, remote state reconciliation, merge-group enforcement and non-atomic race mitigation; externally administered monotonic journal anchors; independent security review and supply-chain review (including images, build tools and CLI providers). Legacy executors do not inherit RC.6 bounded capture. No test corpus is representative of every real agent failure.

The research package itself must still meet the [public release checklist](public-release.md). No permission to merge is created by publication.
