# RC review remediation 02 — changeset observation failures

The synchronous local fixture executor now emits `write_intent` before each CAS and records `observation_unknown` if a write or required observation cannot be confirmed. An unconfirmed operation stops further writes; its signed receipt ends in `MANUAL_INTERVENTION` with `refs: null`, not `COMPLETED` or `COMPENSATED`. A failed precheck may proceed to compensation only after obtaining a fresh ref vector and checking it against the expected vector. No blind compensation is attempted. The `changeset-observation-v1` start marker identifies the new event grammar; the verifier checks the intent/outcome sequence and cannot derive success from an unknown observation. Previous receipts retain their historical verifier and do not authorize new writes.

The synchronous executor's ledger is in memory: this covers handled Git I/O errors, not process death or inability to persist a receipt. For process-interruption recovery use the existing `DurableChangeSet` with a persistent database. It records pending intent before each CAS, retains that intent until a complete ref vector confirms the outcome, and persists a signed `MANUAL_INTERVENTION` state on unreadable refs during execution or recovery. Reopening that terminal state does not retry or compensate automatically. A trusted operator must inspect actual refs and reconcile separately. Pending and completed entries describe intent and confirmed progress, not a fresh snapshot of all refs. Storage or signing failure, database replacement, hostile concurrent actors and atomic distributed transactions remain outside the guarantee.

The local fault tests inject observation failures after forward and compensation writes, in both exception paths, at terminal observation and during durable recovery. They use only synthetic keys and local bare Git fixtures. The original fixture reports and historical v1 receipts are unchanged. No remote authority or production rollback is established. Fresh locked regression, security scans and independent review are required before release.
